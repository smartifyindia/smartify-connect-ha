# Smartify Connect

Lets the Smartify Home app control devices in this Home Assistant. Smartify Connect opens an outbound, encrypted connection to Smartify; nothing on your network is opened to the internet.

## Link it to your Smartify home

1. Start the App, then open **Smartify** in the sidebar.
2. In the Smartify Home app, go to **Add device → Connect Home Assistant**.
3. Scan the QR code on the Smartify page, or type the 8-character code. A code lasts 10 minutes; a new one appears by itself.
4. Choose which devices to add and put them in rooms.

Only the home's owner can link a Home Assistant. Family members see and control the devices the owner adds.

## What Smartify can see

- Only the devices you add in the Smartify app are forwarded, and only the details Smartify needs (on/off, brightness, sensor readings).
- Your Home Assistant token and address never leave this App.
- To disconnect, remove Home Assistant in the Smartify app, or stop or uninstall this App.
